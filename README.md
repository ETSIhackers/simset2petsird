# simset2petsird converter

The purpose of this repo is to provide a starting point for converting history SimSET data to PETSIRD.


## Background
The [Emission Tomography Standardization Initiative (ETSI)](https://etsinitiative.org/)
is working towards establishing a standard for PET Raw Data, called PETSIRD ("PET ETSI Raw Data").
More information is on https://github.com/ETSInitiative/PETSIRD.

## Status
This is still work in progress, but does seem to work, including normalisation. Singles and dead-time info is
currently only passed on for ECAT8 list-mode data (Siemens mMR).
